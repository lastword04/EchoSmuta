# Скрипт добавления всех предметов персонажу

## Описание

Скрипт `add_all_items_to_character.py` добавляет все предметы из таблицы `items` указанному персонажу по одной штуке каждого предмета.

## Использование

### Базовое использование

```bash
cd mining
python add_all_items_to_character.py <character_id>
```

### Пример

```bash
python add_all_items_to_character.py 999da4f0-7cf7-4925-a9aa-22956d1650b4
```

## Что делает скрипт

1. Получает список всех предметов из таблицы `items`
2. Для каждого предмета создаёт запись в `inventory_items` с:
   - `character_id` - указанный ID персонажа
   - `item_slug` - slug предмета
   - `amount` - 1 (одна штука)
   - `expired_date` - NULL (без срока годности)
   - `used_count` - 0 (если у предмета есть параметр `max_used`)
   - `wear` - 0 (если у предмета есть параметр `max_wear`)

3. Выводит статистику:
   - Количество успешно добавленных предметов
   - Количество ошибок
   - Общее количество предметов

## Особенности

### Stackable предметы

Для предметов с `is_stackable = True`:
- Если предмет с такими же параметрами уже существует у персонажа, количество увеличивается на 1
- Если предмета нет, создаётся новая запись

### Non-stackable предметы

Для предметов с `is_stackable = False`:
- Всегда создаётся новая запись, даже если такой предмет уже есть

### Параметры предметов

Скрипт автоматически определяет нужные параметры:
- `used_count` устанавливается в 0 для предметов с `max_used` (масла)
- `wear` устанавливается в 0 для предметов с `max_wear` (мебель)
- Для остальных предметов эти поля остаются NULL

## Требования

- Python 3.13+
- Активированное виртуальное окружение mining сервиса
- Доступ к базе данных (настройки из `.env`)
- Существующий персонаж с указанным `character_id`

## Обработка ошибок

Скрипт обрабатывает ошибки на двух уровнях:

1. **Ошибки отдельных предметов** - выводятся с символом ✗, но скрипт продолжает работу
2. **Критические ошибки** - останавливают выполнение скрипта

## Примечания

- Скрипт не проверяет существование персонажа перед началом работы
- Скрипт не проверяет вес предметов и грузоподъёмность персонажа
- Скрипт не устанавливает срок годности для предметов (можно доработать)
- Для предметов с ограниченным сроком жизни (`min_shelf_life_days`, `max_shelf_life_days`) срок годности не устанавливается

## Возможные улучшения

1. Добавить опцию для установки количества предметов (не только 1)
2. Добавить опцию для установки срока годности
3. Добавить фильтрацию по типу предметов (только эликсиры, только мебель и т.д.)
4. Добавить проверку существования персонажа
5. Добавить dry-run режим (показать что будет добавлено без реального добавления)
