# Ability Parameters - Параметры способностей предметов

Этот документ содержит все уникальные ключи и значения из `ability_parameters` в файлах инициализации предметов.

## Все уникальные ключи ability_parameters

### 1. Характеристики персонажа (Attributes)

#### power_number
- **Описание**: Увеличение силы
- **Тип**: integer
- **Значения**: 1, 3, 5
- **Примеры**:
  - Эликсир Свирепый Воин: +3 силы
  - Эликсир Сила Разума: +1 силы
  - Эликсир Нечистая сила: +5 силы

#### agility_number
- **Описание**: Увеличение ловкости
- **Тип**: integer
- **Значения**: 1, 3, 5
- **Примеры**:
  - Эликсир Преследование: +3 ловкости
  - Эликсир Скорость Звука: +1 ловкости
  - Эликсир Живая Вода: +5 ловкости

#### lucky_number
- **Описание**: Увеличение удачи
- **Тип**: integer
- **Значения**: 1, 3, 5
- **Примеры**:
  - Эликсир Момент Истины: +5 удачи
  - Эликсир Улыбка Фортуны: +1 удачи
  - Эликсир Медвежья песня: +3 удачи

#### attributes_number
- **Описание**: Увеличение всех атрибутов
- **Тип**: integer
- **Значения**: 1
- **Примеры**:
  - Горный дракон: +1 ко всем атрибутам

---

### 2. Здоровье и Мана

#### health_number
- **Описание**: Восстановление здоровья (абсолютное значение)
- **Тип**: integer
- **Значения**: 30, 60, 120, 175, 180, 240, 250, 350, 360, 500
- **Примеры**:
  - Эликсир Капля Жизни: +30 здоровья
  - Эликсир Вечной Жизни: +360 здоровья
  - Жареный Карп: +175 здоровья
  - Копченый Осетр: +500 здоровья

#### health_percentage
- **Описание**: Увеличение здоровья (процент)
- **Тип**: float
- **Значения**: 0.25, 0.5, 0.75
- **Примеры**:
  - Стол обеденный: +75% здоровья
  - Кресло: +50% здоровья
  - Стул: +25% здоровья

#### health_percentage_weared
- **Описание**: Увеличение здоровья при износе мебели (процент)
- **Тип**: float
- **Значения**: 0.0, 0.1, 0.15, 0.25
- **Примеры**:
  - Стол обеденный: +0% при износе
  - Кресло: +15% при износе
  - Ковер: +10% при износе

#### max_health_percentage
- **Описание**: Увеличение максимального здоровья (процент)
- **Тип**: float
- **Значения**: 0.2
- **Примеры**:
  - Речной дракон: +20% к максимальному здоровью

#### mana_number
- **Описание**: Восстановление маны (абсолютное значение)
- **Тип**: integer
- **Значения**: 30, 60, 90
- **Примеры**:
  - Эликсир Волшебная Слеза: +30 маны
  - Эликсир Лагуна Мудрости: +60 маны
  - Эликсир Небесный Поток: +90 маны

#### mana_percentage
- **Описание**: Увеличение маны (процент)
- **Тип**: float
- **Значения**: 0.5, 1.0, 2.0
- **Примеры**:
  - Зеркало: +200% маны
  - Ковер: +100% маны
  - Светильник: +50% маны

#### mana_percentage_weared
- **Описание**: Увеличение маны при износе мебели (процент)
- **Тип**: float
- **Значения**: 0.0, 0.1, 0.25
- **Примеры**:
  - Зеркало: +0% при износе
  - Ковер: +10% при износе
  - Светильник: +25% при износе

---

### 3. Усталость

#### tiredness_percentage
- **Описание**: Изменение усталости (процент, отрицательные значения уменьшают усталость)
- **Тип**: float
- **Значения**: -0.5, -0.4, -0.3, -0.2, -0.15, 0.25, 0.5, 2.0
- **Примеры**:
  - Эликсир Белый День: -20% усталости
  - Эликсир Энергия: -40% усталости
  - Вяленый Карась: -50% усталости
  - Кровать одноместная: +200% усталости (восстановление)
  - Копченый Осетр: -50% усталости

#### tiredness_percentage_weared
- **Описание**: Изменение усталости при износе мебели (процент)
- **Тип**: float
- **Значения**: 0.25, 0.5
- **Примеры**:
  - Кровать одноместная: +25% при износе
  - Кресло: +25% при износе
  - Лавка малая: +50% при износе

---

### 5. Специальные способности

#### dispel_all_effects
- **Описание**: Развеивает все эффекты
- **Тип**: boolean
- **Значения**: True
- **Примеры**:
  - Эликсир Развеивания: развеивает все эффекты

#### invisible_way
- **Описание**: Невидимость в пути
- **Тип**: boolean
- **Значения**: True
- **Примеры**:
  - Призрачный дракон: невидимость в пути

#### summon_additional_beast
- **Описание**: Призыв дополнительного зверя в бою
- **Тип**: boolean
- **Значения**: True
- **Примеры**:
  - Боевой дракон: призыв дополнительного зверя

#### accelerated_recovery
- **Описание**: Ускоренное восстановление персонажа
- **Тип**: boolean
- **Значения**: True
- **Примеры**:
  - Огненный дракон: ускоренное восстановление

#### increase_carry_weight
- **Описание**: Увеличение переносимого веса
- **Тип**: integer
- **Значения**: 120
- **Примеры**:
  - Великанский дракон: +120 к переносимому весу

## Итоговая статистика

**Всего уникальных ключей**: 28

### По категориям:
- **Характеристики персонажа**: 4 ключа (power_number, agility_number, lucky_number, attributes_number)
- **Здоровье и Мана**: 6 ключей (health_number, health_percentage, health_percentage_weared, max_health_percentage, mana_number, mana_percentage, mana_percentage_weared)
- **Усталость**: 2 ключа (tiredness_percentage, tiredness_percentage_weared)
- **Боевые способности**: 8 ключей (attack_against_*)
- **Специальные способности**: 5 ключей (dispel_all_effects, invisible_way, summon_additional_beast, accelerated_recovery, increase_carry_weight)

### Примечания:
1. Все параметры из таблицы полностью соответствуют данным в коде
2. Процентные значения в коде представлены в виде десятичных дробей (0.15 = 15%, 0.5 = 50%, 2.0 = 200%)
3. Отрицательные значения tiredness_percentage означают уменьшение усталости
4. Положительные значения tiredness_percentage означают восстановление (отдых)
